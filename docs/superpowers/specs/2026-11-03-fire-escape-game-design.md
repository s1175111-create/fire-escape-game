# 四场景火灾逃生小游戏设计

## 目标

制作一个面向儿童安全教育的静态网页小游戏。用户先在首页选择家庭、商场、密闭空间或教室，再在各自关卡中点击正确道具，完成火灾逃生知识演练。

## 视觉规范

所有视觉内容严格遵循用户提供的《画风and游戏机制》：纯 2D 平面粘土定格手绘风，圆润软糯的物体边缘，轻微手工颗粒与捏塑痕迹，低饱和暖色，儿童安全教育氛围。不得使用写实摄影、3D 建模、厚重光影、血腥或惊悚表现。除非用户明确要求，不改变此规范。

首页卡片使用已选定的四张无文字 16:9 外景入口封面图：家庭小房子、商场整体入口、地下密闭空间入口、教学楼与教室走廊。关卡内使用用户提供的现有室内场景图，保持原文件不修改。

## 用户流程

1. 首页展示四张场景选择卡：家庭客厅、商场公共区、密闭空间、教室。
2. 鼠标悬停或键盘聚焦卡片时，卡片轻微抬起和放大，出现暖色柔光、粘土边缘高光与“开始演练”标签；触屏设备以点击反馈替代悬停。
3. 选择卡片后进入相应关卡，显示场景图、分数、步骤进度、提示按钮、重玩与返回首页。
4. 正确点击显示绿色知识提示，推进步骤或收集进度；错误点击显示红色提示并扣分。
5. 完成所有必需步骤后，显示暖光淡入、烟雾消散的通关弹窗和该场景安全知识总结。

## 关卡规则

| 场景 | 正确交互 | 错误交互 | 完成条件 |
| --- | --- | --- | --- |
| 家庭 | 湿毛巾、家用灭火器、居家逃生门、报警电话 | 易燃窗帘 | 点击全部正确物品 |
| 商场 | 消防栓、疏散指示牌、安全通道门、湿毛巾取用点、应急广播 | 商场电梯 | 点击全部正确物品 |
| 密闭空间 | 排风开关、防毒面罩、应急手电筒、湿抹布、密闭逃生门 | 杂物纸箱、清水水桶 | 按顺序完成全部步骤 |
| 教室 | 湿毛巾或衣物、灭火器、地面安全箭头、教室门 | 书本、纸巾盒、未完成前直接开门 | 严格按顺序完成全部步骤 |

所有道具热区覆盖图片中对应的黄色虚线与光圈区域，适配鼠标和触摸操作。提示按钮会高亮当前下一步目标。

## 页面与组件边界

- `index.html`：页面结构、首页、关卡面板与弹窗容器。
- `styles.css`：粘土风色彩、版式、响应式规则、卡片和反馈动画。
- `script.js`：场景数据、热区、顺序判定、计分、提示、页面状态与可访问键盘操作。
- `assets/covers/`：四张生成的首页封面图。
- 根目录现有的四张用户图片：只作对应关卡的场景背景，保持原文件不修改。

## 数据与状态

每个场景由独立数据对象描述背景图、热区坐标、正确与错误动作、可选顺序、反馈文案、通关总结。运行时状态仅保存在浏览器内存：当前场景、已完成步骤、得分、错误次数与是否显示提示。重玩将重置当前场景状态，返回首页不删除用户提供的素材。

## 失败与异常处理

当素材加载失败时，界面展示明确的加载失败说明和返回首页操作。错误点击不会阻塞继续游戏；多次错误将加强烟雾提示动画，但不出现恐怖画面。点击尚未解锁的逃生门会解释缺失步骤，不会直接通关。

## 验证标准

- 四张首页封面均为无文字、16:9、符合指定 2D 粘土风。
- 首页卡片有键盘可达的同等聚焦效果，触屏可点击。
- 四个场景均可从首页进入、重玩并返回。
- 每个指定正确和错误热区都能触发对应反馈。
- 教室与密闭空间的顺序规则正确；家庭与商场的收集规则正确。
- 页面在桌面和手机宽度下保持可用，无横向溢出。
