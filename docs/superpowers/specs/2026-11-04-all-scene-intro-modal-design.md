# 四关统一开局剧情弹窗设计

## 目标

家庭客厅、商场公共区、教室与密闭空间四个关卡在进入后，都先显示与密闭空间相同视觉样式的剧情弹窗。玩家点击按钮后，才开始该关的点击式逃生演练。

## 交互设计

- 关卡入口统一调用已有的模态弹窗，不新增页面、场景图片或热区。
- 弹窗眉题固定为“场景剧情”。
- 标题按当前场景动态显示为“家庭客厅警报”“商场公共区警报”“教室警报”或“密闭空间警报”。
- 正文复用各场景已经定义的 `intro` 剧情文本。
- 按钮统一显示“开始演练”。点击后仅关闭弹窗，保留已初始化的该关进度与分数（100 分），玩家即可操作。

## 保持不变的内容

- 四张场景图、静态 2D 布局、热区位置与视觉风格。
- 家庭、商场、教室、密闭空间的现有逃生顺序、扣分、失败、通关与知识反馈逻辑。
- 通关弹窗的“继续探索”行为，以及商场电梯失败后的重新演练行为。

## 实现边界

在 `startGame()` 中将目前只给密闭空间显示的开局模态逻辑改为四关共用；移除其他三关以普通提示气泡展示开局剧情的分支。现有模态按钮的失败与通关分支不改动，使三类弹窗共用同一控件。

## 验收与测试

1. 从首页分别进入家庭、商场、教室、密闭空间，均先出现遮罩剧情弹窗，且背景为相应关卡。
2. 四个标题、剧情文字和“开始演练”按钮与当前关卡对应。
3. 点击“开始演练”后弹窗关闭，黄色热区可点击，初始分数为 100 分。
4. 商场电梯失败后按钮仍重新开始该关；任何关卡通关后按钮仍回到首页。
