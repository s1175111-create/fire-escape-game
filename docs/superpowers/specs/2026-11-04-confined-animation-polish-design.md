# 密闭空间关卡动效强化设计

## 目标与边界

在不改变现有网页结构、场景图片、热区坐标、六步顺序、扣分规则或教室等其他关卡的前提下，强化密闭空间关卡的视觉反馈。现有烟雾、排风提示、道具高亮、回火警示、暖光通关和 Web Audio 提示音全部保留，并以更连贯的分层动画增强教学节奏。

## 动效叠加

### 1. 教学式步骤动画

- 初始烟雾保持可见且缓慢漂移；排风开关完成后，烟雾以渐隐和横向抽离的方式变淡。
- 水桶、湿抹布、面罩和手电筒完成时，在原有高亮的基础上分别增加轻微上浮、水波、展开与呼吸式光晕。
- 每一项动画只在对应步骤完成后出现，热区和步骤条继续作为主要操作引导。

### 2. 开门回火警示

- 不完整准备时点击门，保留 -30 / -15 的现有规则和文字提示。
- 门侧叠加柔和的黑烟涌入、低频红橙闪光与短暂震动；不使用写实火焰、爆炸或恐怖内容。
- 错误状态不阻止玩家继续完成正确流程。

### 3. 光路与通关动画

- 手电筒完成后，画面出现半透明暖黄色光束，指向逃生门区域，提升场景亮度。
- 全部准备完成并点击门后，烟雾完全消散，门侧暖白光扩大，叠加少量星光粒子和“安全撤离”提示。
- 现有 100 分通关弹窗保持不变，只在其显示前增加约 0.95 秒的场景动画。

## 实现方式

- 仅修改 `script.js` 与 `styles.css`：为密闭关卡渲染额外的非交互覆盖层，并按已有 `game.effects` 状态切换 `.confined-*` 类。
- 不新增外部音频或位图资源。沿用现有 Web Audio；所有新增烟雾、光束、水波和粒子由 CSS 渐变、伪元素和关键帧生成，确保首屏加载不增加资源体积。
- 新样式全部以 `.confined-*` 作用域隔离，避免影响家庭、商场和教室关卡。

## 验收

- 原有密闭空间完整流程仍可 100 分通关，三种错误扣分仍为 -30、-15、-10。
- 排风、四个准备道具、手电光路、早开门和通关分别有可辨识的动画状态。
- 小屏页面不产生横向滚动，热区保持可点击。
- 家庭、商场、教室关卡可以正常启动，教室的原有效果不变。
