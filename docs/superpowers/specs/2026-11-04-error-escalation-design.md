# 累计错误两次后的火势升级设计

## 目标

为家庭客厅、商场公共区和教室增加累计两次错误后的火势升级反馈。升级后展示对应的火势变大场景图，并以弹窗解释火势为何扩大。密闭空间保持现状。

## 触发规则

1. 家庭、商场和教室在本轮演练中累计两次错误操作后触发火势升级。
2. 正确操作不会清除已累计的错误次数；同一错误热点的重复点击也计入错误次数。
3. 每个场景每轮最多触发一次升级。达到第二次错误时切图并显示说明弹窗；之后错误不重复弹窗。
4. 商场电梯维持既有行为：第一次点击即结束本轮演练，不计入升级流程。
5. 重开、返回首页或切换场景时，错误累计和火势升级状态均重置。

## 场景呈现

| 场景 | 升级背景 | 说明弹窗 |
| --- | --- | --- |
| 家庭客厅 | 使用用户提供的家庭火势变大图 | 多次错误操作耽误了初期处置和撤离，火势会借易燃物与空气迅速蔓延。 |
| 商场公共区 | 使用用户提供的商场火势变大图 | 多次错误操作拖延疏散时机，浓烟和火势会在公共空间内加快扩散。 |
| 教室 | 保留现有教室火势变大图 | 多次错误操作没有及时完成初期灭火与撤离，火势因此扩大、烟雾也会更浓。 |
| 密闭空间 | 不改动 | 不显示本功能的升级说明。 |

## 实现边界

- 将两张用户提供图片保存为新增、独立的场景素材，绝不覆盖现有清洁场景图。
- 在场景配置中为家庭与商场指定升级背景；教室继续使用已有的升级背景。
- 使用独立的累计错误计数与一次性升级标志，避免依赖现有用于扣分去重的错误集合。
- 复用现有模态框展示升级原因；不改变既有开场、通关或商场电梯失败弹窗。
- 密闭空间不新增图片引用、触发条件或样式变化。

## 验证

1. 家庭、商场、教室各自累计第二次错误后，背景正确切换并显示一次对应说明。
2. 在两次错误之间完成正确步骤，仍在第二次错误触发升级。
3. 同一错误热点连点两次也可触发升级。
4. 商场电梯第一次点击仍立即结束本轮，且不会展示升级说明。
5. 密闭空间错误后保持原有行为。
6. 重开、返回首页和换场景后，升级背景与累计次数均恢复初始状态。
