# 四场景逃生提示停留与通关结算设计

## 目标

四个逃生场景（家庭客厅、商场公共区、密闭空间、教室）中，玩家点击最后一个正确逃生门后，当前场景内的安全提示必须停留足够长的时间。提示应在五秒后自动结束，或由玩家点击右上角圆形“×”提前结束；两种情况都随后展示一次通关结算。

## 交互流程

1. 玩家完成最后一个必需步骤并点击最终逃生门。
2. 维持现有的绿色场景知识提示，内容继续使用该门的正确操作说明。
3. 提示右上角显示圆形“×”关闭按钮，样式沿用现有知识提示的关闭控件。
4. 从提示展示开始计时五秒。
5. 五秒到期时，自动关闭提示并显示通关结算；若玩家先点击“×”，立即关闭提示并显示同一结算。
6. 结算只允许出现一次。重新开始、返回首页或切换场景时，取消尚未结束的计时，避免旧场景触发结算。

## 结算内容

所有场景结算统一使用“🎉 恭喜通关！”作为标题，显示最终得分，并将场景数据中已有的 `summary` 作为标题下方的逃生口诀：

| 场景 | 口诀 |
| --- | --- |
| 家庭客厅 | 拿毛巾、灭小火、快离开、再报警！ |
| 商场公共区 | 听广播、看指示、拿防护、用消防栓、走安全通道，绝不坐电梯！ |
| 密闭空间 | 先排烟、备水源、堵门缝、戴防护、亮视线、再撤离。 |
| 教室 | 捂口鼻、灭小火、辨方向、快撤离，不慌乱、不贪恋物品！ |

## 实现边界

- 在 `script.js` 中为最终步骤建立统一的提示等待与完成入口，而不在四个场景中复制计时分支。
- 现有知识提示的关闭按钮将根据“普通提示”或“待结算最终提示”的状态执行不同的后续行为。
- 结算弹窗继续复用现有模态框；不改动失败、开场剧情或非最终步骤提示的交互。
- 必须清理自动关闭计时器和待结算状态，防止用户迅速重开、回首页时产生过期回调。

## 验证

对四个场景逐一验证：

1. 点击最终逃生门后，安全提示显示约五秒再进入结算。
2. 在五秒内点击提示右上角“×”后，立即进入结算。
3. 每次仅显示一次结算，且标题为“🎉 恭喜通关！”。
4. 结算中显示正确场景的口诀。
5. 在等待期间重开或回首页后，不显示过期结算。
