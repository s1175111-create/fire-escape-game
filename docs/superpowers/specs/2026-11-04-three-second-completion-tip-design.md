# 四场景通关提示三秒停留设计

## 目标

将四个场景完成最后一个必需物品后的安全提示停留时间从五秒统一调整为三秒，再显示“🎉 恭喜通关！”结算弹窗。

## 交互规则

1. 家庭客厅、商场公共区、密闭空间、教室均复用同一条通关收尾流程。
2. 玩家完成最后一个必需物品后，当前绿色安全提示显示三秒。
3. 三秒结束时，自动关闭提示并显示通关结算及对应场景口诀。
4. 玩家点击提示右上角“×”时，立即关闭提示并显示同一通关结算。
5. 普通正确、错误与提示气泡继续沿用现有展示时长。
6. 既有一次性结算保护、切换场景与返回首页时的计时器清理行为不变。

## 实现边界

- 只调整统一通关提示函数传入的等待时间，由 `5000ms` 改为 `3000ms`。
- 不为各场景创建独立计时器或配置项。
- 不变更通关弹窗文字、口诀、关闭按钮或评分逻辑。

## 验证

1. 逐一完成四个场景，确认最终提示约三秒后自动显示通关结算。
2. 在三秒内点击“×”，确认立即显示通关结算。
3. 确认非最终的知识提示仍使用原有时长。
4. 确认不重复显示通关结算。
