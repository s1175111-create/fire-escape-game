# 教室场景一次性操作反馈设计

## 目标

修正教室场景中“捂住口鼻”和灭火粉末会在后续物品点击时重复或残留显示的问题，使两者都成为对应道具点击时的一次性、短暂反馈。

## 交互规则

1. 玩家点击湿毛巾或衣物后，在原有位置显示“捂住口鼻”提示，并在短暂动画结束后自动消失。
2. 灭火器、出口方向、教室门、可选消防栓及错误物品点击时，不重新显示“捂住口鼻”。
3. 玩家点击灭火器后，仅在教室左侧火源附近播放一次白色灭火粉末效果。
4. 灭火粉末动画结束后完全消失；后续步骤不会重新播放或在书本等其他物体附近残留。
5. 重开、返回首页或切换场景时，未结束的一次性反馈自动清理。

## 实现边界

- 将教室的 `cover` 与 `extinguish` 效果从持久状态改为短暂的视觉事件。
- 灭火粉末使用火源附近的固定定位，不依赖后续热点位置。
- 不改变教室步骤顺序、正确与错误判断、积分、火势升级、通关结算或其他场景效果。

## 验证

1. 点击湿毛巾或衣物后，“捂住口鼻”只显示一次并自动消失。
2. 点击灭火器后，粉末只在火源附近出现一次并完全消失。
3. 继续点击出口方向和教室门，确认不会重新显示上述两种效果。
4. 重新演练后，效果可在新的对应步骤中再次正常播放。
