# 家庭钱包陷阱与三秒通关提示设计

## 目标

调整家庭客厅玩法：将画面中的报警电话替换为钱包，钱包成为错误物体；报警操作移至成功撤离后的门口提示。同时将四个场景的最终安全提示等待时间统一为三秒。

## 家庭场景素材

- 新增 `assets/scenes/family-wallet-clean.png`：正常家庭场景的电话已替换为圈选、标注“钱包”的棕色钱包。
- 新增 `assets/scenes/family-wallet-fire-escalated.png`：火势升级家庭场景的电话也已替换为相同的钱包。
- 保留 `family-clean.png` 与 `family-fire-escalated.png`，不覆盖电话版本，以便未来恢复电话玩法。

## 家庭交互

1. 保留 `phone` 物品配置，但将其设为隐藏：不渲染热点，也不计入必需通关步骤。
2. 新建位于原电话位置的 `wallet` 错误热点，使用画面中的黄色圈选与“钱包”标注。
3. 点击钱包时显示错误提示：“逃生时不要贪恋钱包等财物，会耽误撤离。”
4. 家庭必需步骤调整为：湿毛巾、家用灭火器、居家逃生门。
5. 点击居家逃生门后的最终安全提示改为：“正确！撤离到安全区域后，再拨打 119 报警。”
6. 家庭累计第二次错误后继续切换火势升级背景，但使用新增的钱包版升级图。

## 四场景通关计时

1. 家庭、商场、密闭空间、教室完成最后一个必需物品后，绿色安全提示停留三秒。
2. 三秒结束后自动显示“🎉 恭喜通关！”及对应口诀。
3. 玩家点击安全提示右上角“×”时，立即显示同一通关结算。
4. 非最终步骤的知识提示时长、分数、通关结算内容和计时器清理行为不变。

## 范围限制

- 商场、教室、密闭空间的物品与场景素材不因钱包玩法改变。
- 商场电梯的立即失败规则不变。
- 密闭空间不新增火势升级素材或逻辑。

## 验证

1. 家庭开始时显示钱包，画面中不显示电话；钱包点击会显示错误提示。
2. 家庭完成毛巾、灭火器、门后显示“安全区域后再拨打 119”的提示，并在三秒后通关。
3. 家庭累计两次错误后切换到钱包版火势升级图。
4. 原电话版本素材仍保留在项目内。
5. 四个场景均在最终提示三秒后自动通关，且手动关闭可立即通关。
